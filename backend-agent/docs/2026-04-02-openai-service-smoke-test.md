## 摘要

- 在 `backend-agent/scripts/` 新增一个最小 Python 脚本，用于对指定 OpenAI 兼容服务执行一次基础连通性验证，覆盖模型列表查询和一次最小对话请求。

## 背景和目标

- 业务背景：需要快速验证一套 OpenAI 兼容 HTTP 服务当前是否可用，便于后续接入或排障。
- 用户/问题陈述：希望提供一个简单、可直接运行的测试脚本，输入服务地址和密钥后即可判断是否调通。
- 成功标准：脚本可通过命令行或环境变量接收配置，成功访问 `/v1/models`，并完成一次 `/v1/chat/completions` 请求，输出清晰的成功或失败信息。

## 范围

- 范围内：
- 在 `backend-agent/scripts/` 新增独立测试脚本。
- 支持通过命令行参数或环境变量传入服务地址、密钥、模型名和超时时间。
- 对 OpenAI 兼容接口执行最小连通性验证并打印结果。

- 范围外：
- 不改造现有业务代码对外部模型服务的正式接入逻辑。
- 不把真实密钥写入仓库文件。
- 不新增第三方依赖或复杂测试框架封装。

- 待解决问题：待脚本创建后，确认目标服务是否完全遵循 OpenAI Chat Completions 接口格式。

# 交付上线评估标准-用药方案

## 评估结论规则

| 结论 | 判定规则 |
|------|----------|
| PASS | 免责声明、缺失字段提示、保存确认和生成结果均有证据通过。 |
| CONDITIONAL | 生成能力可用，但部分非关键提示或展示存在限制。 |
| FAIL | 免责声明缺失、保存无需确认，或缺失字段未提示。 |

## 业务范围

范围内：用药方案输出展示、医疗免责声明、缺失字段提示、保存前二次确认。

范围外：真实处方审核、药物相互作用知识库完整性、医生签名流程。

## 自动化测试

建议命令：

```powershell
pytest tests/integration/test_cross_cutting_safety.py
```

通过标准：安全边界测试通过，并有手工验收截图补充 UI 行为。

失败处理：标记 `FAIL`；若仅为非关键展示问题，可降级为 `CONDITIONAL` 并记录限制。

## 手工验收

操作入口：用药方案生成与保存入口。

测试数据：完整用药信息 1 组、缺少剂量/频次信息 1 组、存在禁忌提示信息 1 组。

期望结果：输出有免责声明；缺失字段有提示；保存前必须确认；取消确认不保存。

截图/日志证据：生成结果截图、缺失字段提示截图、确认弹窗截图、保存请求日志。

## Agent 评估指令

Agent 需要优先检查医疗安全门禁。只要免责声明或保存确认缺证据，结论必须为 `FAIL`。

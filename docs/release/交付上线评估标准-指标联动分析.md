# 交付上线评估标准-指标联动分析

## 评估结论规则

| 结论 | 判定规则 |
|------|----------|
| PASS | 指标归一化、10 条规则、API、LLM 引用、前端展示、免责声明、医学审核均有证据。 |
| CONDITIONAL | 功能可用，但命中率抽样或医学审核未完成，且有灰度限制。 |
| FAIL | 规则错误、API 缺字段、免责声明缺失，或医学安全要求无证据。 |

## 业务范围

范围内：指标名归一化、组合规则引擎、`combinationAnalysis` 返回、报告分析 LLM 引用、前端组合分析展示。

范围外：跨次报告纵向联动、用药-指标关联、正式诊断建议。

```powershell
mvn "-Dtest=CombinationRuleEngineTest,IndicatorNormalizerTest,StructuredFieldInterpreterTest,RecordControllerTest" test
uv run pytest tests/test_providers/test_llm_service.py
rg -n "指标联动分析仅供参考" frontend/src/components/parse/CombinationAnalysisPanel.tsx
```

通过标准：规则、归一化、字段解释器、记录接口、LLM prompt 相关测试通过。

失败处理：规则或 API 失败标记 `FAIL`；抽样命中率未完成时不得高于 `CONDITIONAL`。

## 手工验收

操作入口：记录详情页和 AI 报告分析入口。

测试数据：覆盖肝功、肾功、糖代谢、甲状腺的样本报告；至少 1 份 UNMAPPED 指标样本。

期望结果：命中规则以卡片展示；AI 解读引用规则结论；免责声明可见；未映射指标不阻塞展示。

截图/日志证据：规则命中截图、API 响应、AI 解读样例、医学审核表、200 样本命中率记录。

## Agent 评估指令

Agent 必须重点检查医学安全证据。没有免责声明或医学审核记录时，结论不得为 `PASS`。没有 200 样本归一化记录时，结论不得高于 `CONDITIONAL`。

## 条件上线限制

当前 `COMBO-P1-002` 已完成医学 AI 辅助审核和研发侧必须修改项处理，但缺少人工医学确认，因此指标联动分析不得判定为 `PASS`。

若业务必须在医学审核前使用，仅建议作为内部灰度、演示或受控试点，且必须满足：

| 限制项 | 要求 | 当前状态 |
|--------|------|----------|
| 展示边界 | 所有规则文案仅表达风险提示，不表达诊断结论或治疗决策 | 已按医学 AI 建议保守化 |
| 免责声明 | 前端联动分析区域展示“仅供参考，不构成医疗诊断建议” | 通过 |
| 规则回滚 | 发现医学争议时可回滚 `combination_rules.json` 或隐藏联动分析区域 | 待发布方案确认 |
| 人工审核 | 10 条规则需完成医学审核签字或等效确认后才能判定 `PASS` | 待验证 |
| 使用范围 | 医学人工确认前不得用于诊断、治疗决策、用药调整、疾病分级、急危重判断或保险风控等场景 | 条件通过 |

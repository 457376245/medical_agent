# 交付上线评估标准-数据权利

## 评估结论规则

| 结论 | 判定规则 |
|------|----------|
| PASS | 授权导出、授权删除、状态查询、下载链接、未授权拒绝和审计均通过。 |
| CONDITIONAL | 授权链路通过，但异步完成或下载链接存在已记录限制。 |
| FAIL | 未授权访问可成功，或导出/删除主链路缺证据。 |

## 业务范围

范围内：数据导出请求、删除请求、状态查询、下载链接、权限校验、审计。

范围外：外部合规审计报告、长期归档策略、跨租户迁移。

## 自动化测试

建议命令：

```powershell
pytest tests/integration/test_encryption_controls.py tests/integration/test_cross_cutting_safety.py
```

通过标准：安全相关集成测试通过，并补充权限拒绝和审计证据。

失败处理：任何权限绕过或跨患者数据污染均标记 `FAIL`。

## 手工验收

操作入口：记录详情页的数据权利操作区。

测试数据：授权用户 1 个、未授权用户 1 个、至少 1 条可导出的记录。

期望结果：授权用户可创建请求；未授权用户被拒绝；导出状态可查；下载链接仅在完成后出现；审计日志可追溯。

截图/日志证据：请求响应、状态页面、下载链接截图、拒绝响应、审计日志。

## Agent 评估指令

Agent 必须把权限和审计作为 P0。只要缺少未授权拒绝证据，结论必须为 `FAIL`。

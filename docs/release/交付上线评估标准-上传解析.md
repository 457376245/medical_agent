# 交付上线评估标准-上传解析

## 评估结论规则

| 结论 | 判定规则 |
|------|----------|
| PASS | P0/P1 项均通过，上传解析主链路和失败重试可复现。 |
| CONDITIONAL | P0 通过，低置信度、修订或证据展示存在非阻断限制。 |
| FAIL | 文件上传、解析状态、失败重试或结果查看任一 P0 缺证据或失败。 |

## 业务范围

范围内：jpg/png/pdf 上传、解析任务状态、失败重试、低置信度证据、结构化结果修订。

范围外：真实 OCR/LLM 质量大样本评估、生产 OSS 权限审计。

## 自动化测试

建议命令：

```powershell
pytest tests/contract/test_upload_endpoints.py tests/contract/test_parse_job_endpoints.py
pytest tests/integration/test_us1_upload_parse_success.py tests/integration/test_us1_parse_failure_retry.py tests/integration/test_us1_low_confidence_revision.py
```

通过标准：测试通过，且失败重试和低置信度修订均覆盖。

失败处理：标记 `FAIL`，补充失败接口、日志和样本文件。

## 手工验收

操作入口：`/records/upload`。

测试数据：jpg、png、pdf 各 1 份；低置信度解析样本 1 份；解析失败样本 1 份。

期望结果：上传成功后能查看任务状态；失败任务能重试；低置信度字段能看到来源证据；编辑后出现新 revision。

截图/日志证据：上传页面截图、解析任务响应、低置信度证据截图、修订前后记录。

## Agent 评估指令

Agent 需要同时读取本文件、US1 手工清单、相关 contract/integration 测试输出。若只有文档声明、没有测试输出或手工证据，结论不得高于 `CONDITIONAL`。

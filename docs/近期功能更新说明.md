# 近期功能更新说明

> 最后更新：2026-04-18

## 一、指标联动分析

### 解决的问题

以前系统只能逐项告诉你"血糖偏高"、"转氨酶偏高"，但不会告诉你这些指标之间的关联意义。现在系统能自动识别多个指标的组合异常模式。

### 如何使用

1. 上传体检/检验报告后，打开记录详情页
2. 在 AI 分析区域下方，新增了一个**指标联动分析**板块
3. 如果你的报告中存在有临床意义的指标组合（如 AST/ALT 比值异常 + GGT 升高），系统会自动以卡片形式展示
4. 每张卡片包含：模式名称、解释说明、建议措施、涉及的指标标签
5. 橙色卡片 = 需要关注（warning），蓝色卡片 = 供参考（info）

### 当前覆盖范围

| 系统 | 规则数 | 示例 |
|------|--------|------|
| 肝功能 | 3 | 酒精性肝损伤模式、胆汁淤积模式、肝细胞损伤模式 |
| 肾功能 | 2 | 肾功能减退信号、肾前性异常 |
| 糖代谢 | 2 | 糖尿病前期风险、血糖控制不佳 |
| 甲状腺 | 3 | 甲减模式、甲亢模式、亚临床甲状腺异常 |

**不需要任何操作**，系统在查看记录时自动运行分析。

## 二、指标名自动归一化

### 解决的问题

不同医院的报告对同一个检验项目可能叫不同的名字（"谷丙转氨酶"、"ALT"、"丙氨酸氨基转移酶"、"GPT"），以前系统无法识别它们是同一个指标，导致趋势对比和联动分析无法工作。

### 如何使用

完全透明，不需要任何操作。系统上传报告后自动将 155 种常见指标名映射到统一编码。这使得：

- 同一指标在不同报告中能正确关联
- 联动分析能跨不同医院的报告工作
- 为后续趋势对比功能提供数据基础

### 匹配策略

系统使用四层匹配策略确保高覆盖率：

1. **精确匹配**：直接匹配指标名或缩写（如 "ALT" → ALT）
2. **括号拆分**：处理 "谷丙转氨酶（ALT）" 这类混合写法
3. **包含匹配**：处理 "谷丙" 这类简写
4. **英文提取**：从混合文本中提取英文缩写再匹配

无法识别的指标不影响使用，只是不参与联动分析。

## 三、AI 对话场景引导

### 解决的问题

以前 AI 助手用同一套通用指令回答所有问题。现在系统会根据当前上下文，自动切换到最合适的对话模式，使回答更有针对性。

### 如何使用

1. 进入 AI 助手页面（`/agent`）
2. 在左侧选择一个疾病档案和记录
3. 发送消息时，系统会自动将场景识别为"报告解读"
4. AI 的回答会更聚焦于：异常指标解读、联动分析引用、后续建议

### 当前支持的场景

| 场景 | 触发条件 | 聚焦内容 |
|------|----------|----------|
| 报告解读 | 选择记录后自动启用 | 异常指标、组合模式、复查建议 |
| 用药审查 | 后续版本通过 UI 切换 | 药物相互作用、指标与药物关联 |
| 临床摘要 | 后续版本通过 UI 切换 | 结构化病历总结、趋势变化 |

## 四、AI 分析引用联动结果

### 与联动分析的配合

当请求 AI 分析一份报告时，AI 会优先引用系统已确认的组合异常模式（如"您的肝功能指标呈现酒精性肝损伤模式"），而不是从零推理。规则引擎给出确定性结论，AI 负责翻译成通俗语言。

### 工作流程

```
报告上传 → 结构化解析 → 指标归一化 → 联动规则匹配 → AI 引用规则结果生成解读
```

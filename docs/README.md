# 文档目录

本目录按文档用途分类。新增文档优先放入对应分类目录，避免继续堆放在 `docs` 根目录。

## 分类

| 目录 | 用途 | 示例 |
| --- | --- | --- |
| `design/` | 方案设计、能力设计、需求设计 | 指标联动分析、Agent 模块增强 |
| `implementation/` | 已落地功能的实现说明、问题修复说明 | 检验阈值误判修复、慢病随访能力增强 |
| `operations/` | 环境、启动、运维、配置迁移说明 | 远端环境脚本清理 |
| `technical-debt/` | 技术债、架构风险、后续治理路线 | MQ 可靠性与环境隔离技术债 |
| `changelog/` | 面向阅读者的功能更新说明 | 近期功能更新说明 |
| `requirements/` | 需求实施追踪文档 | 2026-04-30 需求追踪 |
| `reviews/` | 审查报告、复核记录 | 需求设计 review、交付 review |
| `release/` | 发布相关材料 | release evidence |

## 维护规则

- 文件名保留日期和主题，格式优先使用 `YYYY-MM-DD-主题.md`。
- 需求执行过程中的追踪文档放在 `requirements/`。
- 独立审查或验收报告放在 `reviews/`。
- 技术债不混入需求追踪，统一放在 `technical-debt/`。
- 涉及密钥、连接串、账号密码的内容不得写入文档。
